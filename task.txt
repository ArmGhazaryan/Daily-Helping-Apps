Task Goal:
Fix state persistence for Personal Memory Notes so that saved notes are permanently linked to their respective words and remain visible on the card back when flipping or navigating between flashcards (Next / Prev).

File Scope (STRICT):
- Active JS File: @js/English-Flashcards.js
- Active HTML File: @index.html

CRITICAL INSTRUCTIONS:

1. Synchronize Note State with Card Rendering (@js/English-Flashcards.js):
   - Ensure `userNotes` state object is loaded from `localStorage` (`dha_user_notes`) or Supabase on initialization.
   - Update `renderCard(cardIndex)` function:
     ```javascript
     const currentCard = currentCardsArray[cardIndex];
     const cardNote = userNotes[currentCard.id] || userNotes[currentCard.word.toLowerCase()];

     const notePreviewEl = document.getElementById('cardNotePreview');
     const addNoteBtnEl = document.getElementById('addNoteBtn');

     if (cardNote && cardNote.trim() !== '') {
         // Display note on card back
         if (notePreviewEl) {
             notePreviewEl.textContent = `💡 Note: ${cardNote}`;
             notePreviewEl.style.display = 'block';
         }
         // Update button text on card front
         if (addNoteBtnEl) {
             addNoteBtnEl.innerHTML = '✏️ Edit Note';
             addNoteBtnEl.classList.add('has-note');
         }
     } else {
         // Hide note preview if no note exists
         if (notePreviewEl) {
             notePreviewEl.style.display = 'none';
             notePreviewEl.textContent = '';
         }
         // Reset button text on card front
         if (addNoteBtnEl) {
             addNoteBtnEl.innerHTML = '✏️ Note';
             addNoteBtnEl.classList.remove('has-note');
         }
     }
     ```

2. Card Navigation Event Listeners:
   - Ensure Next (`#nextBtn`), Prev (`#prevBtn`), and card tab selectors explicitly call `renderCard()` so note state updates synchronously whenever the active card changes.
   - When saving/deleting a note in `#noteModal`, update `userNotes` in memory and `localStorage`, then immediately call `renderCard(currentCardIndex)` to update the live DOM without requiring a manual page refresh.
