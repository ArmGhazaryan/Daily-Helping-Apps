Task Goal:
Convert the web application into a fully functional Progressive Web App (PWA) with offline caching capability, app installation manifest, and service worker registration.

Target Files to Create/Modify:
- Create `manifest.json` in the root directory.
- Create `sw.js` (Service Worker) in the root directory.
- Update `index.html`, `HTML-Files/workout-tracker.html`, and `HTML-Files/English-Flashcards.html` to register the service worker and link the manifest.

Detailed Requirements:

1. Web App Manifest (`manifest.json`):
   - Set `name`: "Daily Productivity & Fitness", `short_name`: "DailyApp".
   - Set `start_url`: "/index.html" (or relative `./index.html`).
   - Set `display`: "standalone", `background_color`: "#0f172a", `theme_color`: "#0f172a".
   - Define standard icon entries (192x192 and 512x512 formats).

2. Service Worker (`sw.js`):
   - Implement a "Stale-While-Revalidate" or "Cache First" network strategy.
   - Cache essential static assets: HTML files, CSS files, JavaScript files, and core icons.
   - Handle the `install` event to pre-cache critical app shell files.
   - Handle the `fetch` event to serve cached resources when offline, while updating cache in the background when online.
   - Handle the `activate` event to clean up outdated cache storage versions.

3. HTML Integration & Service Worker Registration:
   - Add `<link rel="manifest" href="../manifest.json">` to all HTML file headers.
   - Add meta tag `<meta name="theme-color" content="#0f172a">`.
   - Add inline/external script to register `sw.js` safely:
     ```javascript
     if ('serviceWorker' in navigator) {
       window.addEventListener('load', () => {
         navigator.serviceWorker.register('/sw.js')
           .then(reg => console.log('PWA Service Worker Registered!'))
           .catch(err => console.error('SW Registration Failed:', err));
       });
     }
     ```

Verification Steps:
- Check DevTools -> Application tab -> Manifest & Service Workers to confirm successful PWA installation status.
- Test offline functionality in DevTools (Network -> Offline mode) to verify the app shell loads without network connectivity.
