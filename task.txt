Task Goal:
Enable unauthenticated (guest) users to view and interact with DHA Official Global flashcards without being logged in.

Requirements:

1. Unauthenticated Fetch Logic (`js/flashcards.js`):
   - Execute `fetchFlashcards()` on initial page load regardless of active session state.
   - IF user is LOGGED OUT (`session === null`): Query Supabase for flashcards where `is_global === true`.
   - IF user is LOGGED IN: Query Supabase for flashcards where `is_global === true` OR `user_id === session.user.id`.

2. Guest Experience & Auth Guarding:
   - Guest users can freely flip cards, listen to audio pronunciation, and filter by levels (A1 to C2).
   - If a guest user clicks the Heart (Favorite) button OR the "+ Add New Word" button:
     * Prevent the action.
     * Show a toast message: "Please sign in to save favorites or add custom words."
     * Open the Auth Modal (`#auth-modal`).
